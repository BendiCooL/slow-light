An entry for the make.fun bounty
[Make the AI Judge Feel Awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

`main.ts` (Node 22, stdlib only, no network) writes one short English text to
`/output/entry.txt` — a quiet scene under old starlight, written to relax the
reader through image and rhythm rather than instruction.

Run it with `node main.ts` (or `MAKEFUN_OUTPUT_DIR=<dir> node main.ts` to
choose the output directory).
